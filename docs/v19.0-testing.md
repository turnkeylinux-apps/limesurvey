# LimeSurvey 19.0 testing

## Source and update decision

Debian 13 Trixie does not package LimeSurvey. The appliance installs the
official LimeSurvey 7.0.11 Community Edition complete release, which is the
current maintained line. The build pins and verifies the reviewed archive
SHA-256 `cef826be3e32ae5dd443b1d8f222fc9f3214688115705271c114d4492d7ca9ab`.
PHP 8.4, MariaDB 11.8, Apache and required extensions come from signed Trixie
repositories.

LimeSurvey upgrades are administrator-supervised because releases can require
database and extension compatibility work. The README points to the official
Community Edition procedure and the acceptance test verifies the live official
download channel.

## Economical preflight evidence

A disposable Trixie container installed the required PHP and MariaDB packages,
verified and unpacked the pinned complete release, completed LimeSurvey's real
CLI installer, authenticated through the web and REST boundaries, imported an
upstream sample survey, and read the survey through the REST editor API and
MariaDB.

## Deferred issues

- The focused acceptance imports an upstream sample survey instead of driving
  the JavaScript editor with a browser. It validates the editor's authenticated
  REST view of persisted survey state while avoiding a costly browser lane.
- Outbound email delivery depends on site-specific relay and DNS settings. The
  test covers the documented local Postfix service and listener.
